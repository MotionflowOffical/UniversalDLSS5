# UniversalDLSS5 v0.4.1

v0.4.1 is a compatibility bug-fix release focused on the external x64 NRHost contract used by 32-bit games and late-attached D3D12 recovery routes.

## Feature-18 external-host contract

The NRHost path is now aligned with the known-good in-process Feature-18 implementation:

- uses `NVSDK_NGX_D3D12_AllocateParameters` for the mutable Feature-18 parameter block instead of capability parameters;
- initializes the signed snippet with the fixed signed application ID, the selected runtime directory, and a null Init_Ext parameter block;
- explicitly sets both DLSS indicator-axis parameters to zero;
- removes non-contract `PaperWhiteScale`, `TransferStrength`, and `ColorStrength` writes from the private Feature-18 parameter block;
- uses `D3D11_RESOURCE_MISC_SHARED | D3D11_RESOURCE_MISC_SHARED_NTHANDLE` for bridge/host textures;
- creates shared texture handles with `GENERIC_ALL`;
- keeps fence-based synchronization and explicitly flushes the D3D11 producer after signaling the cross-process fence.

These changes target the two failures observed in v0.4.0 testing: `DXGI_ERROR_ACCESS_DENIED` device removal in Half Sword/Teardown recovery mode and near-black edge/residual-like output in the 32-bit D3D9 path.

## D3D9 color handling

Classic D3D9 and D3D9Ex compatibility frames are now treated as display-referred SDR/sRGB when they enter the canonical D3D11 pipeline. This preserves the same neural proxy transfer-domain handling used by the working SDR paths.

## NRHost launch

The external host launch now explicitly requests a hidden window in addition to `CREATE_NO_WINDOW`.

## Native fast paths

Native D3D11 and exact-queue native D3D12 paths remain unchanged. The v0.4.1 fixes affect only routes that use the external x64 NRHost or compatibility frontends.

## Validation targets

Recommended Windows validation for this build:

- Half Sword — late-attached D3D12 recovery / external NRHost;
- Teardown — late-attached D3D12 recovery / external NRHost;
- Call of Duty 4: Modern Warfare — x86 classic D3D9 / Bridge32 / x64 NRHost;
- The Long Drive — native D3D11 regression check;
- Cyberpunk 2077 — native D3D12 regression check.

v0.4.1 remains experimental and still requires game-by-game runtime validation on Windows.
