# UniversalDLSS5 v0.3.2

v0.3.2 is a performance, stability, and controller usability update built on the v0.3.1 HDR and D3D12 safety work.

## Performance and diagnostics

- Direct Feature-18 execution uses D3D12 timestamp queries for neural GPU timing.
- Diagnostics distinguish Feature-18 GPU execution from synchronized pacing wait time.
- Synchronization events are reused instead of recreated every frame.
- Neural scratch/control resources are allocated only when their selected mode needs them.
- Low-resolution optical-flow preparation is skipped when the active motion route does not use it.
- Proven D3D12 presentation queues stop paying continuous queue-discovery bookkeeping until revalidation is needed.
- Missing game-guide adapters are negatively cached to avoid repeated hot-path probing.
- Final Feature-18 processing is not downscaled as a performance shortcut.

## Stability

- Native D3D11 keeps the conservative owned-source and fresh backbuffer-view path, fixing the black-screen regression introduced by an unsafe direct-view optimization.
- Detach now enters an unload state, disables new hook work, waits for in-flight detours to leave, and only then destroys swapchain pipelines, neural state, and MinHook.
- Calls that arrive during detach are forwarded directly to the original graphics APIs.

## Controller UI

- The application selector has independent mouse-wheel scrolling and a scrollbar when needed.
- Changing selection keeps the selected application inside the visible viewport.
- Refresh immediately shows a short `Refreshing...` state and ignores repeat clicks during the minimum feedback interval.

## Version metadata

The application, Windows file/product resources, CMake/CPack project version, controller UI, build/release banners, attach logs, NRHost, direct NGX engine string, Streamline engine string, runtime README, and package verification rules all report v0.3.2 / 0.3.2.0 as appropriate.

Historical v0.3.1 documentation remains versioned as v0.3.1.
