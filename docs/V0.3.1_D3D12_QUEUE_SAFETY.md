# UniversalDLSS5 v0.3.1 — D3D12 queue/backbuffer safety

v0.3.1 targets a D3D12 crash observed in Hitman World of Assassination after neural processing had already started. Turning game motion and depth off did not prevent the crash, which ruled out temporal-guide capture as the primary failure.

## What changed

- D3D11On12 is no longer initialized from the most recently observed same-device DIRECT queue.
- Existing swapchain backbuffers are registered with the D3D12 barrier tracker. Command lists that transition those backbuffers are correlated with the DIRECT queue that executes them.
- Late-injected D3D12 swapchains require two matching backbuffer-touch proofs before the queue is trusted. A queue supplied directly to DXGI swapchain creation is trusted immediately.
- If queue ownership cannot be proven, UniversalDLSS5 stays in passthrough rather than touching the D3D12 swapchain.
- The game swapchain backbuffer is no longer wrapped directly by D3D11On12. UniversalDLSS5 copies it to an injector-owned D3D12 color resource, processes that resource through D3D11On12/Feature 18, then copies the result back on the proven presentation queue.
- A low-overhead crash-stage marker plus vectored exception logger records whether a serious exception was observed during queue proof, backbuffer acquisition, pre-copy, D3D11On12 acquire, neural processing, release, post-copy, or the underlying DXGI Present call.

## Hitman testing

Use 1x neural passes and Synchronized pacing first. Motion/Depth can remain Auto; the queue/backbuffer safety path is independent of the guide source. If the title still exits, open Diagnostics -> Open attach logs and send the newest `attach-<PID>.log`. v0.3.1 appends the active crash stage for access violations/illegal-instruction/stack/heap-corruption exceptions.

## Compatibility behavior

A D3D12 game that uses enhanced barriers or otherwise never exposes a provable backbuffer transition may remain in passthrough after late injection. That is deliberate: v0.3.1 prefers no processing over guessing a DIRECT queue and risking device/game corruption.
