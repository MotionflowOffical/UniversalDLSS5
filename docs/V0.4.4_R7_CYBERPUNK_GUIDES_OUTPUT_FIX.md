# v0.4.4 r7 — Cyberpunk guide continuity and output-proof fix

This patch addresses the remaining D3D12 recovery failures observed in Cyberpunk 2077 after r6.

- Streamline `sl::Constants` are tracked per viewport instead of as one global snapshot.
- DLSS input-color extent is tracked per viewport and used for motion-vector normalization.
- Provider generations carry viewport identity so unrelated Streamline viewports cannot be merged.
- Completed owned depth/motion snapshots persist across multiple Presents until replaced or expired; they are no longer single-use.
- Post-submit snapshots prefer shareable SRV-friendly resource descriptors instead of preserving engine-only depth/UAV flags.
- Explicit Streamline/NGX depth buffers keep the provider 30% render-scale acceptance threshold through D3D11 depth preparation.
- NRHost now supplies Feature-18 subrect base X/Y parameters, matching the in-process NGX path.
- Recovery diagnostics report the debug mode actually applied by the injected bridge and whether the final D3D12 backbuffer copy completed before Present.
- Cached external-host diagnostics preserve execution location/backend kind.

The output-proof fields intentionally bump the shared-control ABI to 21; controller, bridge and host must be rebuilt/replaced together.
