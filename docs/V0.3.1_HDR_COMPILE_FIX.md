# v0.3.1 HDR Windows SDK compile fix

This patch removes an invalid `IDXGISwapChain3::GetColorSpace1()` call. DXGI exposes `SetColorSpace1` and `CheckColorSpaceSupport`, but no matching getter.

UniversalDLSS5 now tracks successful `SetColorSpace1` calls per swapchain. For swapchains that already existed before injection, the initial color-space state is inferred from the containing `IDXGIOutput6::GetDesc1()` result until an observed `SetColorSpace1` call makes the state authoritative.

The NRHost Windows macro definitions are also guarded to avoid `WIN32_LEAN_AND_MEAN` and `NOMINMAX` redefinition warnings when CMake already defines them.
