# UniversalDLSS5 v0.4.4

v0.4.4 is a recovery-safety update for late-attached D3D12 games.

## Changes

- Removed injected cross-queue fence waits/signals from the game's D3D12 dependency graph.
- Recovery does not mutate game command lists and does not inject cross-queue waits. Volatile Streamline snapshots use a separate same-queue post-submit copy; volatile NGX resources remain excluded from recovery.
- Present-safe Streamline game depth/motion is used directly in recovery. Shorter-lived Streamline guides are now captured without mutating the game command list: UniversalDLSS5 appends its own copy command list immediately after the provider list on the same queue and publishes only injector-owned snapshots.
- NGX transient game resources remain available on the native/exact D3D12 path but are not consumed by late-attach recovery without a safe lifetime contract.
- D3D11 recovery completion now uses a short, non-fatal wait. If work is still in flight, UniversalDLSS5 bypasses the frame instead of blocking Present for seconds.
- Existing native D3D11/D3D12 fast paths, D3D9 compatibility, x64 NRHost, 1x-4x NR passes, and automatic detach remain intact.

This update specifically addresses a Cyberpunk 2077 recovery failure where the GPU could reset while UniversalDLSS5 was waiting for recovery D3D11 work to finish.
