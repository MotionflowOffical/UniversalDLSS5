# v0.2.8 SwapCtx API compile fix

This package fixes a Windows bridge compile regression introduced by the stable renderer-election update.

`src/bridge/dxgi_hooks.cpp` used `SwapCtx::api` when publishing status for a renderer suppressed by primary-renderer election, and when remembering whether a swapchain was D3D11 or D3D12, but the exported `SwapCtx` definition did not contain that member.

The context now contains:

```cpp
GraphicsApi api{GraphicsApi::Unknown};
```

A regression assertion was added to `tests/v029_architecture_wiring_tests.cpp` so future packages fail their portable verification if the state field is removed while the renderer-election path still depends on it.
