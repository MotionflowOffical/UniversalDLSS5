# D3D11 black-screen regression fix

This patch addresses the black output observed after the first v0.3.2 performance pass in native D3D11 games such as The Long Drive.

The performance pass allowed direct SRV sampling and cached RTV reuse for shader-bindable D3D11 swapchain backbuffers. A native D3D11 engine can expose compatible bind flags without guaranteeing that Present-time direct sampling or retained backbuffer views are safe for its swapchain lifecycle. The pipeline can therefore execute successfully while reading or presenting an invalid/black frame.

The fix restores the known-safe native D3D11 behavior:

- copy/resolve the current swapchain backbuffer into the injector-owned source texture before preprocessing;
- create a fresh backbuffer RTV for the final blit;
- keep direct SRV/RTV reuse only for the injector-owned D3D12On12 staging texture, whose lifetime and bind contract UniversalDLSS5 controls.

No neural resolution reduction is introduced. Feature 18 continues to evaluate at the selected full processing resolution.
