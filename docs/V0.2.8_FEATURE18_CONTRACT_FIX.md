# v0.2.8 Feature-18 contract correction

This revision targets the near-black / edge-only output observed after Feature 18 reported successful evaluation.

The screenshots are not consistent with the motion-vector debug view. With zero motion that view is neutral gray, while the captured frames are >80-90% near-black and strongly edge-correlated, which is characteristic of a difference/residual-like image.

The direct in-game NGX path is now aligned with the known-working signed Feature-18 contract:

- `NVSDK_NGX_D3D12_AllocateParameters` is used for the Feature-18 parameter block instead of capability parameters.
- Signed snippet `Init_Ext` uses application ID `0x0876232C`, the runtime directory containing `nvngx_dlssnr.dll`, and a null parameter block.
- Core init also uses the runtime directory as its application/data directory.
- Shared D3D11/D3D12 textures use `SHARED | SHARED_NTHANDLE`, not keyed-mutex sharing. Synchronization remains fence-based.
- Shared handles are opened with `GENERIC_ALL`, matching the verified interop path.
- `DLSS.Indicator.Invert.X.Axis` and `.Y.Axis` are explicitly set to zero.
- Non-contract generic `PaperWhiteScale`, `TransferStrength`, and `ColorStrength` writes were removed from the private Feature-18 parameter block. Those controls remain available to UniversalDLSS5's compositor only.
- Existing create/evaluate submission and D3D11->D3D12 flush/fence synchronization fixes are retained.

For validation, start with Motion = Zero and Debug view = Final output. If the result is still edge-only, switch to Raw neural output and capture diagnostics. The diagnostics should also be checked for the exact `Debug view:` line to rule out the Difference visualization.
