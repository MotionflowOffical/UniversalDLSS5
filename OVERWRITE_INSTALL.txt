UniversalDLSS5 v0.3.2 - performance, detach stability + controller UI
=====================================================================
This ZIP contains exactly one top-level folder: UniversalDLSS5\

To install over the previous source tree:
1. Close UniversalDLSS5 and the target game.
2. Extract this ZIP into the parent directory that already contains UniversalDLSS5.
3. Choose Replace/Overwrite for existing files.
4. Run BUILD_WINDOWS.bat again.

The fixes are already integrated; no .patch file needs to be applied manually.

This update keeps the v0.3.1 HDR/D3D12 safety work and adds:
- real Feature-18 GPU timestamp telemetry separated from synchronized wait time;
- lower hot-path allocation, synchronization, optical-flow, guide-discovery, and queue-discovery overhead;
- a D3D11 black-screen regression fix while retaining safe owned-resource optimizations;
- quiescent detach/unload ordering that drains in-flight hooks before graphics/neural teardown;
- independently scrollable application selection with a visible scrollbar;
- brief Refresh feedback even when process enumeration completes immediately;
- public/runtime/package version metadata updated consistently to v0.3.2.
