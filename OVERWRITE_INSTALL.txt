UniversalDLSS5 v0.3.1 - D3D12 queue/backbuffer safety + real game guides
=====================================================================
This ZIP contains exactly one top-level folder: UniversalDLSS5\

To install over the previous source tree:
1. Close UniversalDLSS5 and the target game.
2. Extract this ZIP into the parent directory that already contains UniversalDLSS5.
3. Choose Replace/Overwrite for existing files.
4. Run BUILD_WINDOWS.bat again.

The fixes are already integrated; no .patch file needs to be applied manually.

- crash-stage telemetry for queue/copy/On12/neural/Present failures;
- game-supplied NGX/Streamline motion/depth capture and D3D12/D3D11 guide fallbacks;
- persistent global System / Light / Dark controller appearance;
- synchronized/adaptive/asynchronous pacing and 1x-4x neural passes;
- public version metadata updated consistently to v0.3.1.
