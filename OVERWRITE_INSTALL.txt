UniversalDLSS5 v0.4.3 - UE5 D3D12 Recovery Lifetime Isolation
=============================================================
This ZIP contains exactly one top-level folder: UniversalDLSS5\

To install over the previous source tree:
1. Close UniversalDLSS5 and the target game.
2. Extract this ZIP into the parent directory that already contains UniversalDLSS5.
3. Choose Replace/Overwrite for existing files.
4. Run BUILD_WINDOWS.bat again.

The changes are already integrated; no .patch file needs to be applied manually.

Current v0.4.x renderer support includes:
- native D3D11 and exact-queue D3D12 fast paths;
- late-attach D3D12 recovery using same-queue D3D12 copies plus an explicit shared D3D12/D3D11 color surface;
- x86-game -> x64 NRHost Feature 18 routing;
- D3D10/10.1, D3D9Ex, classic D3D9, OpenGL, and Vulkan compatibility frontends;
- automatic bridge detach after a target application exits and renderer activity stops;
- quiescent manual detach with DetachedResident as the last-resort safety mode.

Compatibility frontends remain isolated from proven native D3D11/D3D12 frames.
There is no desktop/screen-capture fallback and no intentional Feature-18 color downscale.
