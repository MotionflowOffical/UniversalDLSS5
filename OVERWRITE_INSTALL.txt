UniversalDLSS5 v0.2.8 - Stable renderer/scheduler + multipass/UI update
=====================================================================
This ZIP contains exactly one top-level folder: UniversalDLSS5\

To install over the previous source tree:
1. Close UniversalDLSS5 and the target game.
2. Extract this ZIP into the parent directory that already contains UniversalDLSS5.
3. Choose Replace/Overwrite for existing files.
4. Run BUILD_WINDOWS.bat again.

The fixes are already integrated; no .patch file needs to be applied manually.

This update keeps the working signed Feature-18 contract fix and adds:
- stable primary-renderer election for multi-process/multi-swapchain applications;
- non-flickering soft neural scheduler backpressure with a 3-8 slot GPU ring;
- per-slot shared resources so in-flight frames cannot overwrite each other;
- 1x-4x neural processing, with passes 2-4 isolated as same-frame refinements;
- System / Light / Dark controller themes and modern owner-drawn controls;
- background process-tree maintenance so opening the controller does not enumerate/inject on every UI tick.
